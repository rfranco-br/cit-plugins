# cit-plugins

Internal Claude Code plugin registry for CI&T, managed by [Centaurus](https://centaurusdirectory.web.app).

## Installing plugins

```
/plugin marketplace add https://centaurusdirectory.web.app/marketplace.json
/plugin install <plugin-name>@cit-plugins
```

## For plugin authors

Submit your plugin at https://centaurusdirectory.web.app/submit.
Each approved plugin is hosted on a dedicated branch (`plugin/<name>`) in this repo.
